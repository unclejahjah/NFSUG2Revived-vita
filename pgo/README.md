# PGO profile

`nfsu2.proftext` is the clang profile the Vita build uses by default (`NFSU_PGO_DEFAULT=ON`; `-DNFSU_PGO_DEFAULT=OFF` or `-DNFSU_PGO_USE=<indexed .profdata>` to change it). It is the text form with the checkout path replaced by `@NFSU_SOURCE_DIR@`: clang names file-local functions by their absolute source path, so CMake writes a copy with the real path into the build folder and indexes it with `llvm-profdata` at configure time.

Recorded 2026-11-22 on a real Vita (444 MHz, core 3 available) from 0.8.5 (d90423a) with the release settings `tools/build.py` passes: instrumented build (`-DNFSU_PGO_GENERATE=ON`, no dev tools), six runs with audio on, each ended by quitting the app after a fixed time (the profile is written every 30 s): the start of a Resort Loop race (`boot_track=4014`, 3 AI, vita graphics, `music_hw_decode=on`, `audio_mixer_split=on`, about 60 s of race), a URL race (`boot_mode=url`, track 4711, 5 AI, about 60 s), a full Resort Loop race (3 AI, 9 profile writes), free roam driven by a `pad_script` (throttle and weaving, about 100 s), the front end into the garage (`boot_steps`, `boot_quit_after=150`), and a drag race (`boot_mode=drag`, `boot_manual=off`, throttle held by a `pad_script`) with about two minutes on the results screen afterwards; its scripted presses did not reach the replay. Each run's `ux0:data/NeedForSpeedUnderground2/nfsu.profraw` was fetched, the six merged unweighted with `llvm-profdata merge`, then written as text with `llvm-profdata merge --text` and the absolute source path replaced by `@NFSU_SOURCE_DIR@`.

Build in a clean folder after changing the profile: objects compiled against another profile do not link (ThinLTO reports conflicting `ProfileSummary` values).

Refresh it after large code changes, especially after regenerating `src/ug2/generated`: functions whose code changed lose their profile data.
